## 这份探针证明了什么、没证明什么

- **证明了**：一次 issue 触发的探针运行能把改动落到自己的 PR 分支并开成可评审的 PR；交付没有越界去改业务代码。

一句话：这次证明的是**交付链路通**，不是**探针语义正确**。
