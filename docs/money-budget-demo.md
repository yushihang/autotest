# 预算演示（money budget demo）

这个目录用来验证「单次任务有成本上限」这条设计约束是否真的生效：任务花到预算上限必须停下来，而不是继续重试。

| 项 | 值 |
|---|---|
| 预算 | $0.1 |
| 预期结果 | 失败 |
| 用途 | 证明预算确实能拦住任务 |

## 这为什么是一次「失败」的演示

演示任务的验收命令是 `false`，它永远返回非零退出码。所以：

- 任务跑到预算或验收这一步必定报失败——这是**设计如此**，不是环境问题。
- 失败的证据应该被完整记录：花了多少、停在哪一步、还差什么。
- 不允许为了「让它变绿」而修改验收命令本身，那样演示就失去意义了。

## 和正常任务的区别

正常任务的目标是「测试跑通、PR 可合并」；演示任务的目标是「预算到点能停住、失败能被如实报告」。两者都要求同一件事：**结果可复现，报告不修饰**。
